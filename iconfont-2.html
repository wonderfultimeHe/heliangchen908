图标，是一条路径。

与字体图标不同，Lucide 交付的是真正的矢量图形： JS 扫描 data-lucide 属性，把占位的 <i> 标签替换成 <svg>——每枚图标就是几条描边路径。 下面这根羽毛，正在被一笔一笔画出来。

现场绘制

新元素需再调一次 createIcons

JS 后来生成的元素不会被自动替换——每画一枚，都要再喊一次 lucide.createIcons()。

用法图例

三行可用
<script src="cdn/lucide.min.js"></script>

<i data-lucide="heart"></i>

<script>
  lucide.createIcons(); // 把 i 替换成 svg
</script>

替换发生在 JS 运行时：查看源码看到的只是占位的 i 标签。

缩放改 width / height，换色改 color——描边颜色会继承文字色。

图标名用短横线连接单词，如 shopping-cart、thumbs-up。
